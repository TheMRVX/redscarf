# RedScarf

سیستم ربات آپلودر تلگرام، مینی‌اپ اختصاصی وب و پنل مدیریت ادمین.

- [راهنمای توسعه، گردش کار گیت و قوانین مشارکت (CONTRIBUTING.md)](CONTRIBUTING.md)
- [تاریخچه نسخه‌ها و تغییرات (CHANGELOG.md)](CHANGELOG.md)

## ساختار فنی (Technical Stack)

- **Bot Backend:** Python 3.12 + Aiogram 3.x
- **Web & API:** FastAPI + Uvicorn
- **Reverse Proxy & SSL:** Caddy Server
- **Database:** SQLite
- **Deployment:** Docker & Docker Compose
