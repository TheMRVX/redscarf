# ربات آپلودر تلگرام + مینی اپ + پنل ادمین

مینی اپ مثل یک **سایت** است: مطالب (پست‌ها) با کاور و توضیحات و یک یا چند **دکمه دانلود** (مثلاً چند پارت). کاربر فقط مطالب را می‌بیند؛ فایل‌ها هیچ‌جا نمایش داده نمی‌شوند و فقط وقتی روی دکمه دانلود بزند، ربات فایل را برایش می‌فرستد.
همه‌چیز (برند، لوگو، رنگ، چیدمان، متن‌ها، دسته‌بندی، مطالب و لینک) از پنل ادمین قابل تنظیم است و فقط ادمین (رمز پنل + آیدی‌های `ADMIN_IDS`) می‌تواند مدیریت کند. فارسی و انگلیسی.

---

## ۱) کارهایی که توی تلگرام می‌کنی (۵ دقیقه)

1. به **@BotFather** پیام بده ← `/newbot` ← اسم و یوزرنیم ← **توکن** را کپی کن.
2. به **@userinfobot** پیام بده ← **آیدی عددی** خودت را کپی کن.

## ۲) سرور و دامنه

1. یک VPS خارج از ایران بخر (Ubuntu 22.04 یا 24.04، حداقل ۱ هسته و ۲ گیگ رم).
2. دامنه را بخر و در DNS یک رکورد **A** بساز که به IP سرور اشاره کند (مثلاً `files.example.com`).
   - اگر از Cloudflare استفاده می‌کنی: اول **ابر نارنجی را خاکستری کن (DNS only)** تا گواهی SSL گرفته شود. بعداً می‌توانی روشنش کنی و SSL mode را روی **Full** بگذاری.
3. چند دقیقه صبر کن تا DNS اعمال شود.

## ۳) اتصال به سرور و نصب Docker

با Termius (یا هر برنامه SSH) به سرور وصل شو (`ssh root@IP_SERVER`) و این‌ها را اجرا کن:

```bash
curl -fsSL https://get.docker.com | sh
apt install -y unzip
```

## ۴) گذاشتن پروژه روی سرور

فایل `tg-uploader.zip` را با بخش SFTP همان Termius (یا با دستور `scp tg-uploader.zip root@IP_SERVER:/root/`) روی سرور بریز. بعد:

```bash
cd /root
unzip tg-uploader.zip
cd tgbot
cp .env.example .env
nano .env
```

در `nano` مقادیر را پر کن (`BOT_TOKEN`، `ADMIN_IDS`، `DOMAIN` بدون https، `ADMIN_PASSWORD` یک رمز قوی).
ذخیره: `Ctrl+O` ← `Enter` ← `Ctrl+X`.

`STORAGE_CHANNEL_ID` را فعلاً خالی بگذار (مرحله ۶).

## ۵) اجرا

```bash
docker compose up -d --build
docker compose logs -f app
```

(با `Ctrl+C` از نمایش لاگ بیرون بیا؛ برنامه همچنان اجراست.)

- ربات: توی تلگرام `/start` بزن.
- مینی اپ: `https://دامنه-تو/app/` (دکمه منوی ربات هم خودکار تنظیم می‌شود)
- پنل ادمین: `https://دامنه-تو/admin/` (ورود با `ADMIN_USER` و `ADMIN_PASSWORD`)

## ۶) کانال ذخیره‌سازی (توصیه می‌شود)

فایل‌ها داخل یک کانال خصوصی نگه‌داری می‌شوند؛ هم پشتیبان است، هم برای فایل‌های بزرگ‌تر از ۲ گیگ (با پریمیوم) لازم است.

1. در تلگرام یک **کانال خصوصی** بساز.
2. ربات را به عنوان **ادمین** کانال اضافه کن (دسترسی ارسال پیام بدهد).
3. یک پیام دلخواه داخل کانال بفرست. ربات برایت (ادمین) پیامی می‌فرستد که شامل خط `STORAGE_CHANNEL_ID=-100...` است.
4. همان خط را در `.env` بگذار و اجرا کن:

```bash
nano .env
docker compose up -d --force-recreate app
```

## ۷) استفاده روزمره

1. **افزودن فایل:** فایل را از حساب ادمین برای ربات بفرست (تا ۲ گیگ، با پریمیوم تا ۴ گیگ). ربات ذخیره‌اش می‌کند. فایل خیلی بزرگ را با اکانت پریمیوم مستقیم داخل کانال ذخیره‌سازی آپلود کن؛ ربات خودکار ثبتش می‌کند.
2. **ساخت مطلب:** پنل ادمین ← **مطالب** ← افزودن: عنوان، توضیحات، تصویر کاور (آپلود از همان‌جا)، دسته‌بندی؛ بعد با «افزودن فایل» هر تعداد **دکمه دانلود** اضافه کن (برای هر کدام عنوان دلخواه مثل «پارت ۱ - 1080p» بنویس، جابه‌جایی با ↑↓).
3. **مخفی/نمایش:** تیک «نمایش داده شود» را بردار تا مطلب (و دانلودهایش) از دسترس خارج شود.
4. **ظاهر:** پنل ← **برند و ظاهر**: اسم، لوگو، بنر، رنگ‌ها، فونت، چیدمان مطالب (کارت بزرگ / فهرست / دو ستونه)، ترتیب بخش‌ها و پیام استارت ربات؛ با پیش‌نمایش زنده.
5. **حذف خودکار فایل ارسالی:** پنل ← برند و ظاهر ← «ارسال فایل به کاربر»: مدت (دقیقه، حداکثر ۱۴۴۰) را تنظیم کن؛ `۰` یعنی غیرفعال. بعد از این مدت، فایلی که ربات به کاربر فرستاده از چت خودِ کاربر پاک می‌شود (فایل اصلی در کانال می‌ماند). پیام هشدار برای کاربر هم قابل خاموش کردن است. پیش‌فرض ۱۰ دقیقه است.
6. **تصاویر:** کاور هر مطلب با هر نسبتی (پوستر عمودی، افقی، مربع) **کامل و بدون برش** نمایش داده می‌شود.
7. **لینک اشتراک:** کنار هر مطلب دکمه «لینک ربات» هست (`t.me/ربات?start=p_شماره`)؛ هرکس بزند، همان مطلب (کاور، متن و دکمه‌های دانلود) داخل چت ربات برایش ارسال می‌شود. کنار هر فایل هم «کپی لینک» هست که فایل را مستقیم می‌فرستد.

نکته: فایلی که به هیچ مطلب منتشرشده‌ای وصل نباشد، با دکمه‌های مینی اپ قابل دانلود نیست. اسم و عکس خود ربات را فقط از @BotFather می‌شود عوض کرد.

## ۷.۱) عضویت اجباری و محدودیت دانلود

هر دو در **پنل ← برند و ظاهر ← «عضویت اجباری و محدودیت دانلود»** هستند و جدا از هم روشن/خاموش می‌شوند.

**عضویت اجباری در کانال**
1. ربات را **ادمین** همان کانال(ها) کن (برای بررسی عضویت، تلگرام این را لازم دارد).
2. تیک «عضویت اجباری…» را بزن و کانال‌ها را بنویس، **هر خط یک کانال**:
   - کانال عمومی: `@mychannel` یا `t.me/mychannel`
   - کانال خصوصی: `-1001234567890|https://t.me/+لینک‌دعوت` (آیدی عددی + لینک دعوت)
3. دکمه **«بررسی کانال‌ها»** را بزن؛ برای هر کانال نشان می‌دهد ربات ادمین هست یا نه (قبل از ذخیره هم کار می‌کند).
4. ذخیره کن. از این به بعد کاربری که عضو نباشد، موقع زدن دانلود پنجره/پیام «اول عضو شوید» می‌بیند و بعد از عضویت با «عضو شدم» فایل را می‌گیرد.

نکات: ادمین‌های ربات (`ADMIN_IDS`) معاف‌اند. اگر تلگرام نتواند عضویت را بررسی کند (مثلاً ربات ادمین نیست)، کاربر **بلاک نمی‌شود** تا اشتباه تنظیمات کل دانلودها را قفل نکند؛ برای همین حتماً دکمه «بررسی کانال‌ها» را بزن. فقط **دانلود** قفل می‌شود، دیدن مطالب آزاد است.

**محدودیت دانلود**
تیک «محدودیت دانلود…» را بزن و «حداکثر تعداد فایل» و «بازه (ساعت)» را بگذار؛ مثلاً ۵ فایل در ۲۴ ساعت. هر بار ارسال فایل (از مینی اپ یا لینک ربات) یک واحد حساب می‌شود. کاربر وقتی به سقف برسد، پیام می‌گیرد که چقدر دیگر صبر کند. ادمین‌ها معاف‌اند.

## سرعت با مطالب زیاد

مینی اپ هر بار فقط **یک صفحه (۱۲ مطلب)** را از سرور می‌گیرد؛ با اسکرول یا «نمایش بیشتر» صفحه بعد می‌آید. جستجو و فیلتر دسته‌بندی هم روی سرور انجام می‌شود و متن کامل و فایل‌های هر مطلب فقط وقتی بازش کنی لود می‌شود. پس با هزاران مطلب هم صفحه اول چند کیلوبایت است. لیست‌های پنل ادمین هم صفحه‌بندی و جستجو دارند.

## ۸) به‌روزرسانی و پشتیبان‌گیری

- همه اطلاعات (دیتابیس، تصاویر آپلودی، کلید) در پوشه `data/` است. پشتیبان: `cp -r data data-backup` یا کپی همان پوشه به جای دیگر.
- فایل‌های اصلی داخل کانال تلگرام‌اند و نیاز به پشتیبان جدا ندارند.
- ری‌استارت: `docker compose restart app` ‌| توقف: `docker compose down`

## ۹) دامنه پشتیبان (اگر دامنه فیلتر شد)

1. دامنه جدید را به IP سرور وصل کن.
2. در فایل `Caddyfile` اول خط اول را این‌طور تغییر بده: `{$DOMAIN}, domain2.example.com {`
3. `docker compose up -d --force-recreate caddy`
4. در پنل ادمین ← برند و ظاهر ← «آدرس مینی اپ» را روی `https://domain2.example.com/app/` بگذار و ذخیره کن.

## به‌روزرسانی نسخه جدید روی سروری که قبلاً نصب کردی

`.env` و پوشه `data/` داخل زیپ نیستند، پس روی همان پوشه باز کردن امن است:

```bash
cd /root
unzip -o tg-uploader.zip
cd tgbot
docker compose up -d --build
```

دیتابیس خودکار ارتقا پیدا می‌کند و اطلاعات قبلی می‌ماند.

## مشکلات رایج

| مشکل | راه‌حل |
|---|---|
| مینی اپ باز نمی‌شود | `DOMAIN` را در `.env` و رکورد A را چک کن؛ `docker compose logs caddy` را ببین (گواهی SSL). |
| ربات جواب نمی‌دهد | `docker compose logs app`؛ توکن را چک کن. |
| «ربات را استارت کنید» | کاربر باید یک بار ربات را Start کرده باشد؛ مینی اپ خودش لینک شروع را باز می‌کند. |
| ربات فایل را به کانال کپی نمی‌کند | مطمئن شو ربات ادمین کانال است و `STORAGE_CHANNEL_ID` درست است. |
| رمز پنل را فراموش کردم | `ADMIN_PASSWORD` را در `.env` عوض کن و `docker compose up -d --force-recreate app`. |

## ساختار فنی (برای توسعه)

- `app/bot.py` ربات (aiogram) ‌• `app/api.py` API مینی اپ و پنل ‌• `app/db.py` دیتابیس SQLite
- `static/miniapp/` مینی اپ ‌• `static/admin/` پنل ادمین ‌• `Caddyfile` گواهی SSL خودکار
- فایل‌ها با `copyMessage` از کانال برای کاربر کپی می‌شوند؛ پس ربات هیچ‌وقت فایل را دانلود/آپلود دوباره نمی‌کند و محدودیت ۲۰ مگابایت دانلود Bot API (و نیاز به Local Bot API Server) مطرح نیست.
- اعتبارسنجی مینی اپ: امضای HMAC روی `initData` تلگرام.
